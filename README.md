# 校园工具箱

面向福建信息职业技术学院平潭校区的 Android 日常工具。

## 快递快捷入口

首页直接打开拼多多包裹、拼多多身份码和抖音订单，不用在多个 App 里反复找入口。

## 校园地图

搜索教学楼、宿舍、食堂和校内公共地点，查看自己的位置，并打开高德步行导航。支持自定义地点和校园原图对照。

## 照片水印

选择照片或拍照，添加学院、班级、姓名、座号、学号和拍摄时间。可以调整显示内容、顺序和位置，设置导出文件名，另存新照片，不覆盖原图。

## 个人课程表

手动添加课程，或登录学校平台导入当前学期。保存后可离线查看周课表和今日课程，点开查看教室、教师和节次，也可以备份、恢复课表。

## 倒计时

记录考试、比赛、假期或纪念日，查看还有多少天或已经过去多少天，支持每年重复和可选提醒。

## 应用更新

检查本仓库 GitHub Releases 发布的正式版本，查看更新内容，自主选择下载和安装。支持下载进度、取消和重试。
