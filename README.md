# 校园工具箱

给福建信息职业技术学院平潭校区同学用的日常工具。

## 快递快捷入口

打开首页就能点拼多多包裹、拼多多身份码和抖音订单。

## 校园地图

搜索教学楼、宿舍、食堂和校内公共地点，查看自己的位置，打开高德步行导航。也可以添加自己的地点、对照校园导览图找楼。

## 照片水印

给活动照片添加学院、班级、姓名、座号、学号和拍摄时间，需要哪些就选哪些。可以调整顺序、位置，选择是否显示“姓名：”等字样，并设置保存的文件名。生成新照片，不覆盖原图。

## 个人课程表

手动添加课程，或在“个人课程表 → 管理 → 学校导入 / 备份与恢复”中登录学校平台，导入当前学期。

保存后不用一直登录，没网或学校平台关闭时也能看周课表、今日课程。点课程查看名称、教室、教师和节次；换手机前可以备份课表，再从备份恢复。

## 倒计时

记下考试、比赛、假期或纪念日，查看还有多少天、已经过去多少天。支持每年重复，也可以开启提醒。

## 应用更新

在设置里检查新版、查看更新内容，自己选择下载、安装或稍后再说。
