# 校园工具箱

给福建信息职业技术学院平潭校区同学用的日常工具。

[下载安装包（国内）](https://cnb.cool/campus-toolbox/campus-toolbox/-/releases) · [GitHub 备用](https://github.com/dufan82/campus-toolbox/releases/latest)

在下载页选择 `.apk` 文件安装。升级时直接覆盖安装，不要先卸载，保留已保存的课表和资料。

## 快递快捷入口

打开首页就能点拼多多包裹、拼多多身份码和抖音订单。

## 校园地图

搜索教学楼、宿舍、食堂和校内公共地点，查看自己的位置，打开高德步行导航。也可以添加自己的地点、对照校园导览图找楼。

## 照片水印

给活动照片添加学院、班级、姓名、座号、学号和拍摄时间，需要哪些就选哪些。可以直接拖动水印，调整顺序、黑白字、横竖排列、底色和字号，选择是否显示“姓名：”等字样，并设置保存的文件名。生成新照片，不覆盖原图。

## 课程表

手动添加课程，或在“课程表 → 管理 → 学校导入 / 备份与恢复”中登录学校平台，导入当前学期。

保存后不用一直登录，没网或学校平台关闭时也能看周课表、今日课程。点课程查看名称、教室、教师和节次；换手机前可以备份课表，再从备份恢复。

教室或课程有变动时，可以手动检查，先看差异，再选择只更新今天及以后的安排。也可以在“课表 → 管理 → 每日自动检查课表”里开启每天早上的检查，手动修改会保留。默认关闭，登录过期时需重新登录，省电或断网可能延后。

## 倒数日

生日、纪念日、体测、考试、比赛和假期可以直接选，也可以自己写标题。日期点日历选择，查看还有多少天、已经过去多少天；点记录可以修改或删除。支持每年重复和可选提醒，提醒时间也可以直接选择。

## 首页和设置

三个快递入口始终固定在首页。其他工具可以调整顺序或隐藏；底部可以直接切换首页、课表和我的。水印资料、首页布局、快递链接和更新集中在“我的”里。

“我的”页面下方有意见反馈入口，在线问卷暂未开放。

## 应用更新

在设置里检查新版、查看更新内容，自己选择下载、安装或稍后再说。
