# 1.1.0 原生界面与打包

依据：用户确认的 `design-preview/离线预览.html`，以及“可以打包吧”。继续原生 Kotlin 工程，不使用网页壳，不新增运行依赖，不修改包名或删除本地数据。

## 实施顺序

- [x] 六字段白名单、内置模板及导出命名模型；先运行失败测试再实现。
- [x] 绿白原生 UI：首页三个快递直达置顶、简化内容页与资料页。
- [x] 导出弹窗：选字段、手动改名、JPG/PNG；高清输出仍复用原渲染器。

- [x] 签名比对、1.1.0 APK、源码归档、使用说明和验证结果。

## 边界与决定

- 已有代码在 `feature/campus-watermark` 分支，但源码都是既有未提交文件；在原工程继续，不创建空工作树、不提交或覆盖整批用户文件。
- 基线 JVM 测试已通过。当前没有连接的 adb 设备，使用项目专用模拟器测试，不自动安装到真实手机。
- 被移除的五个字段只退出展示/编辑/模板，不删除已保存的原资料值；避免覆盖升级丢失旧数据。
- 命名默认班级、姓名、座号，点选顺序即命名顺序；空值跳过，非法字符安全替换。学号默认不参与。
- 只记住命名字段选择，手动文件名只留在编辑会话；恢复/旋转不自动触发保存。
- 缓存任务相互隔离，同名重复保存创建新相册条目，不覆盖原照或先前分享文件。
- 不保证第三方 App 实际打开指定订单/取件页面，保留原有受限包名、回退与诊断。
