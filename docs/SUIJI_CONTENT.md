## 核实程度与权限

- 前三条短链接均只作正常跳转解析，得到真实抖音 note 地址；页面返回 acrawler 验证页，HTTP 200不等于读到正文。没有绕过验证、读取登录 Cookie 或抓取私有接口。第二、三篇的署名与短摘录来自用户提供的分享文字，正式标题并未核实；第一篇作者未知，显示“作者待核实”。

- 第一篇使用用户本轮提供的完整稿，不润色、不加结尾。正文单独保存在忽略的 `private/suiji-review-assets/suiji_private_review.json`，仅显式启用的 Debug 私人预览加载。公开 `stories.json` 无该全文，Release 无私人资产。私人预览不等于转载授权。

- 其余七条已打开原始页面核对作者与内容；未读到的图片/评论不自行补写。第10条是较长页面中的“你需要联网么”小节，非独立文章；当前没有核实到稳定直达评论/小节锚点，所以只链接真实原页。没有把评论作者错署给作品发布者。

- 《一个人的生日》的作者[关于页](https://www.geedea.pro/about/)注明站点默认 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。该条记录保留许可，但本轮没有整理其完整文本和图片，仍只显示独立介绍与原文入口；没有把“已许可”误判成“已有完整正文”。以后收入正文要同时保留署名、原始链接与许可，区分页面可能另有署名的第三方材料。

- 《背影》用[维基文库原文页](https://zh.wikisource.org/wiki/背影)的转录正文，不含现代译注；保留朱自清署名、原段落和原有繁体字。页面列1925年作品、作者1948年去世与公版标记，未声称已对照初刊影印本。其余网站公开发布不代表允许全文转载。

## 数据与公开展示

- `app/src/main/assets/stories.json`：schema2，十条目录与可公开正文。来源、作者、简介、许可、排序与页面代码分离。
- `legacy_stories.json`：保留旧12篇示例和稳定ID，仅归档，普通精选不再展示；已有收藏仍能打开，阅读进度和草稿文件不迁移。
- `StoryProvenance`：区分 `douyin_post / douyin_image / douyin_comment / other_platform / user_submission`；作品发布者、评论作者与定位分别保存。授权字段未知时不公开全文。
- 服务端和客户端均判权。未授权的完整审核稿只在管理员私有集合；公开DTO、云端公开记录和客户端缓存不含全文。正文被撤权后，联网拿到新元数据即清除旧全文；完全离线的设备无法实时知道撤权，这不是远程擦除。
- `authorized/public_domain/user_authorized` 且有正文才按全文阅读；介绍页不覆盖原来的全文阅读位置。首页工具ID仍是 `story`。前三篇本地稳定顺序不被远程重排。
- 云端故事可以依据准确原文来源替代本地同一条的内容，保留本地ID/收藏/进度；不同评论、不同锚点不合并，不用易变标题去重。

## 私人预览与公开构建

```powershell
.\gradlew.bat :app:assembleDebug -PsuijiPrivateReview=true --offline
# 普通 Debug 不传该参数；Release 即使传参也不加入私人资产。
.\gradlew.bat :app:assembleRelease --offline
```

该预览仍为1.8.3/code30，不是新版线上更新。不得将带私人正文的 Debug 包上传到 GitHub、CNB 或分发给同学。当前正式版签名不变；安装同版本测试包时须由系统确认，勿卸载/清数据。
