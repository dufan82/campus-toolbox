## 如何接手

1. 先读根目录 AGENTS.md、STATUS.md、TASKS.md，再核对实际版本和 `git status`。
2. 为当前任务更新状态，保留已有业务和用户改动。
3. 改代码后运行相应测试，记录真实结果；文档改动不要冒充应用重新验收。
4. 收尾同步四份管理文件。未获新的任务授权，不自行推送或创建 PR。

GitHub 是提交时的共享副本，不是后台自动同步服务。私有仓库需要相应读取权限，公开仓库也要由另一个会话主动读取。
