# 1.3.1 · 纯内容改为可选

## 修正范围

用户明确“只显示内容”应是选项，不是固定去掉字段名。WM-003 增加标题旁的“只显示内容”复选框：默认勾选输出值，取消则输出“姓名：值”等字段名。位置仍默认右下，选择顺序、空值跳过、学号默认隐藏和独立文件名不变。仍为原生 Kotlin，不新增依赖、不上传照片、不推送 GitHub。

- Models.kt：EditorConfig 新增 contentOnly 默认 true；formattedFields 按开关返回纯值或字段名+值，预览/导出仍共用此函数。
- LocalStore.kt：配置与模板 JSON 读写开关；v1/v2 缺失该字段时默认 true，保持 1.3.0 行为，不重置资料/位置。
- ContentPanel.kt：复用标题行，不额外占一行；有明确勾选状态、48dp 触控高度和无障碍说明，回调读取当前配置，不回退拖动位置。
- 新 ContentModeTest：真实图片下切换、旋转/重开记忆、位置及命名独立、模板与旧缺省值。
- PlainWatermarkTest：两种格式、空值/敏感字段规则与命名独立。
- ExportDialogFlowTest：两种状态原生截图，标签模式实际 PNG 保存；纯内容 PNG 仍由现有图片导出测试覆盖。
- UpgradeFixtureTest：旧 APK 阶段用其已有无参构造器建立默认配置，避免新增可选字段导致测试夹具的二进制签名不匹配，不为测试增加生产兼容层。
- 版本 1.3.1 / versionCode 5；包名、签名方式和权限不变。
