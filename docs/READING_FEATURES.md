每日诗句保持独立。随记是普通工具，可排序/隐藏/恢复；十条来源目录、私人稿和公开正文分别管理，详见[SUIJI_CONTENT.md](SUIJI_CONTENT.md)。阅读支持原文、收藏、字号、进度和上一篇/下一篇。投稿沿用已接通的CloudBase；新增精选管理尚未部署。

## 首版本地预览记录

本轮沿用校伴1.8.2/code29，不改签名、包名、发布渠道和已有数据；没有提交、推送或发布。

## 使用

- 首页顶部仅保留诗句、右对齐出处和设置按钮。点击诗句可以复制、换一句；切换页面与旋转不换句，下一次冷启动重新抽取，避开最近40条。
- “小故事”是独立普通工具，可调整顺序、隐藏、恢复，也可从全部工具打开。列表筛选分类和收藏，阅读页可调整16–18sp字号、收藏并保留阅读位置。
- 投稿入口只在故事列表右上角。当前未配置接收服务，只存本机草稿；标题2–30字、正文100–5000字、分类必选、昵称选填，展示授权需主动勾选。校验、保存草稿均不发送网络请求。
- 学校“检查更新”显示最近检查时间、结果和实际变动内容。有变化时可查看更新前后日期、课程、教室、教师、节次。检查历史与课表/备份分开存储，不影响07:00去重规则。

## 本地边界

诗词为独立数组`poems.json`，小故事为独立`stories.json`，不混用模型。诗词历史只存ID；故事收藏、阅读位置、字号及草稿仅写`stories-local-v1.json`，复用原子JSON文件和串行后台IO。未知/损坏故事数据保留原件，不覆盖成空记录。首页三项快递入口不进入普通工具目录。

诗词数据来源与许可见[POETRY_SOURCES.md](POETRY_SOURCES.md)，MIT版权声明另随APK放入`assets/licenses/chinese-poetry-MIT.txt`。故事来源见[STORY_CONTENT.md](STORY_CONTENT.md)。项目整体许可不变。

## 投稿接入建议及已核实限制

腾讯问卷可作为候选，无需给App增加SDK或自行部署服务器：官方[产品功能](https://cloud.tencent.cn/document/product/1304/49131)列有多行文本、单/多选、知情确认与后台统计；可用必填确认题取得规则和展示授权，由开发者人工审核后随版本收录，不直接公开答卷。

官方[填答限制](https://cloud.tencent.cn/document/product/1304/135539)将“填答需要登录验证”和“允许匿名填答”分开：后者（对问卷编辑者隐藏昵称、账号）当前标为付费版本能力。因此不能把免费关闭强制登录描述成保证平台完全匿名。本轮未购买或开通任何服务。原生草稿只使用匿名/昵称，不自动收集真实身份。

后续接入步骤：
1. 新建**独立故事投稿问卷**，不能复用意见反馈问卷。设置标题、五类分类、多行正文、选填昵称、两项必选权益确认，不要求学号/真实姓名或定位。
2. 设置规则：投稿者应原创或有合法投稿权限；授予审核后的非独占App内展示许可，保留署名和应有权利，不保证采用。公布撤稿/版权投诉方法，选填联系方式不对外公开。
3. 手机和未登录环境实测5000字多段落、授权必选、后台接收、平台身份信息设置和免费版限制；不要只看预览就认为已接收。腾讯官方FAQ有[协议设置说明](https://cloud.tencent.com.cn/document/faq/1304/134309)，但本次未证实任何具体账号的5000字上限或付费选项权限。
4. 取得实际公开**填写链接**（不是`/edit`管理地址），填写`StorySubmissionConfig.PUBLIC_FORM_URL`。当前为空；不预置虚构URL、认证凭据或反馈问卷地址。
5. 一旦有有效配置，“投稿”直接交给系统浏览器打开真实外部表单，不把本机草稿拼进URL、不自动传输，避免先在App填写一遍再要求重填。外部页打不开时返回本机草稿页并说明。
6. 审核通过后，使用新稳定故事ID加入故事数据并注明真实署名/来源。撤稿时移除故事，但不擅自清空旧收藏/阅读记录；缺失ID不导致闪退。

## 手机预览验收

1. 首页三个快递入口首屏可见；首页↔课表↔我的反复切换，看首页是否仍有新页面式跳转。实际手感以ARM手机为准，不用软件GPU模拟器承诺帧率。
2. 点诗句复制和换句，返回首页及旋转，核对出处在独立右对齐行、句子不被截断；强停后重开应换句。
3. 隐藏/恢复/移动小故事，重启后布局应保留；其他工具顺序、课表、资料不变。
4. 阅读长文、换字号、收藏，退出重进检查进度；小屏、大字体可滚动。
5. 投稿页应显示未开放；填草稿、校验、返回、重进，内容保留且无提交动作。
6. 学校检查必须由用户正常登录；真实学校变更、07:00厂商后台和登录保留由手机验收。离线测试只用合成课表，不接触真实通行登记。
