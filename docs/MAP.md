# 平潭校区地图

1.7.1兼容过渡版：用户已明确确认高德针对本App的公开使用授权和校园导览图的安装包分发许可。公开APK包含地图与原图；源码仍不携带Key及独立图片。非debuggable构建也读取已有本机地点草稿，LOCAL_MAP_EDITING保留可选的本机自定义/隐藏/移点操作，不修改公共内置文件、不上传，也不启用Android调试。下面历史验证数字仍属原1.5.1，当前发布检查见STATUS。

福建信息职业技术学院平潭校区；原生绿白界面，保留首页快递、水印及本地资料。

公开源码不包含校园导览原图，使用前需自行确认图片使用权限并放到`app/src/main/assets/pingtan-reference.png`。未提供时原图页显示读取失败，不影响地图、水印和快递。下面的原图操作适用于已补入素材的本机构建。

## 使用

1. 首页打开校园地图。首次同意隐私后才初始化高德SDK；拒绝不影响其他工具。
2. 上方只有搜索框，不再显示“校园/附近”或分类。名称在本机可见目录搜索，不向高德提交校园搜索词。
3. 唯一有坐标的匹配项自动选中；多个匹配项临时显示在搜索框下方，点选后收起。无坐标项标待核对、不导航。空查询恢复全部可见圆点，不展开永久名单。
4. 点地图圆点或搜索结果后，只显示这一个地点的导航卡片，没有下方全部地点列表。点“高德步行导航”主动打开官方高德App；未安装会提示。距离仅是直线估算。
5. “我的位置”才申请系统前台定位；允许大致位置、拒绝仍可浏览。定位过期隐藏旧点，不记轨迹；后台/离开地图停止位置监听。
6. “查看全校”清空查询、恢复全校标记。右上“原图”仍可选楼/高亮，图面红色“当前位置”是原标牌静态内容，不是GPS。
7. “地点”菜单仅新增/管理自定义、显示隐藏、退出核对。名单选择、删除已标位置、导出及重复原图菜单入口已移除；自定义改名/移动/确认删除只影响本机。
8. “原图”选楼后仍可回高德长按真实位置确认；不把校区中心或手机位置代填。新增自定义无图面锚点时明确“原图暂未关联”。
9. 说明可查看隐私政策或撤回同意；本机标点不自动上传、同步或更新其他人。

## 位置数据

本版按用户最新附件完整快照内置35处坐标（30手动记录、5供应方记录）、2个自定义名称、9项隐藏。45内置名称加2自定义，默认可见38项；3项无坐标：实训2楼、心理健康教育示范基地、校区南门。前两项为最新文件已撤掉的位置，不能从旧版合并回来。

新增校区北门及“实训2北门/实训2南门”坐标分别绑定自身ID；按最新快照更新6号楼和快递驿站，不挪用其他楼的入口坐标。用户提供的记录不是专业测绘或可通行保证。原始JSON和旧APK保持不变。

本机维护草稿仍为完整权威快照，非debuggable兼容版升级也不会自动覆盖本机人工增删。因此旧安装的点数可能与新内置不同；不要清除应用数据。schema1/2兼容，schema2保存名称、分类、坐标、显示状态；底层JSON编解码保留用于本地存储，不代表仍有文件导出UI。

## 显示与布局

校园底图隐藏原文字后叠加所需地点，保留供应方标识。核对位置期间临时显示底图原文字。圆点/选中光环与屏幕标签避让逻辑沿用1.5.0；屏幕坐标仅用于文字排布，不写成经纬度。

横屏搜索与单卡放在左侧可滚动区域，地图在右侧；竖屏导航卡在最下方。错误/加载和定位状态按需显示，默认不堆计数和权限说明。大字体下允许换行和滚动，不缩小系统字体。现有应用为浅色主题，本轮未新增深色主题。
