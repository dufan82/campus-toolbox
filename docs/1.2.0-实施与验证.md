# 1.2.0 界面精简与静默跳转

## 本轮范围

按用户实机截图修改现有 Kotlin / Android Views 应用，不重建项目、不新增依赖，也不更改三个快递入口的链接或目标包名。参考截图仅用于理解界面，没有上传截图或提取身份码内容。

1. 成功启动快递页面链接时返回空提示，不再弹成功 Toast；完全失败或首页回退仍给出可操作的错误说明。
2. 编辑器上方为六项编号标签，下方为实时照片预览。标签与导出命名共用 FieldChips，选择互相独立；取消再选会排到最后。
3. 去掉模板列表、模板保存、四分页和样式参数页，只保留当前一种水印设置。旧资料和模板数据不删除，旧样式不强制重置，新用户仍使用默认简洁样式。
4. 资料可从“编辑资料”修改，拍摄时间可直接编辑；继续支持选图、系统相机、拖动水印、原分辨率保存、PNG / JPEG、命名和系统分享。

## 文件与职责

- `ui/FieldChips.kt`：新增共用六字段标签，编号、点选顺序、选中状态和触控反馈。
- `ui/ContentPanel.kt`：六标签、编辑资料入口、拍摄时间输入，删除重复的全字段长表单和排序弹窗。
- `ui/WatermarkActivity.kt`：选项上、照片下，移除多模板及分页界面；按剩余高度限制选项面板，保留软键盘适配和导出逻辑。
- `ui/ExportDialog.kt`：复用 FieldChips，保留独立的命名配置和手动文件名。
- `ui/MainActivity.kt`、`express/ExpressActivity.kt`、`express/ExpressLauncher.kt`：成功跳转静默，失败反馈保留，更新内置说明。
- `app/build.gradle.kts`：版本 1.2.0 / versionCode 3，包名、签名方式和权限不变。
- `SimplifiedEditorTest.kt`：新增真实界面布局、点选顺序/持久化、成功路由静默和横屏可用性回归。
- `ReviewRegressionTest.kt`：旧复选框定位改为稳定标签；保留拖动后更改字段不丢位置、真实软键盘、资料恢复等测试。
- `ExportDialogFlowTest.kt`：截图版本更新，继续执行真正的命名、取消、旋转、PNG 保存和原图校验。

以上 Kotlin 文件均位于 `app/src/main/java/cn/campuslife/assistant/` 下相应目录；设备测试在 `app/src/androidTest/java/cn/campuslife/assistant/`。

## 验证方式

本机构建和单元检查：`./build.ps1 -Task check`。

专用测试设备：Android 16 / API 36、720 × 1280、emulator-5580，使用模拟相机，不启用电脑摄像头。完整设备测试命令：

```powershell
$env:ANDROID_SERIAL='emulator-5580'
./gradlew.bat :watermark-core:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:connectedDebugAndroidTest
```

先写测试再修改：`verification/red-editor-v1.2.log` 记录旧实现三项预期失败；`verification/landscape-v1.2.log` 复现横屏预览被挤没。修复后横屏与真实软键盘专项通过，见 `verification/compact-green-v1.2.log`。最终全套结果见 `verification/final-suite-v1.2.log`。

覆盖升级：`verification/verify-release-v1.2.mjs` 仅作用于专用模拟器，在旧 1.1.0 APK 中写入明确测试资料、旧字段、个人模板和快递设置，再覆盖安装新 APK，比较非空私有设置文件哈希，并在新版读取验证。样本不含真实身份信息，不写入交付 APK 默认值。

最终结果：41 项 JVM 单元测试通过；28 项设备测试中 27 项通过，1 项发布夹具按设计跳过；覆盖升级夹具 seed / verify 各 1 项另行通过。Android lint 为 0 错误、41 警告（包括依赖/目标版本提示、字符串拼接、View 构造器及 KTX 建议，未掩盖警告）。

`verification/release-verification-v1.2.json` 保存实际 APK 哈希、版本、非空私有设置哈希和升级结果；`verification/v1.2-screenshots/` 为真实原生运行截图。测试照片只打入设备测试 APK，不在交付 APK 中。

## 已知边界

- 第三方应用最终落地页面仍由对应 App、登录状态和链接有效性决定。静默成功只表示系统接受了启动请求，不宣称验证了目标页。
- Android 8–9、各手机厂商的相机/相册行为和极大系统字体仍需真机补测；没有宣称覆盖所有设备。
- 横屏选项区需要滚动，预览和保存操作保持可见。未制作深色主题；当前使用固定浅色设计。
- 不包含批量水印、二维码模板、照片提交或网络同步。
- 历史五个内置模板定义和旧模板读写模型仍留在核心/存储层以保护已有数据，但不在简化界面中提供多模板功能。
