# 1.3.0 · 水印位置与纯内容输出

## 范围与文件

完成 WM-001 / WM-002，仍为 Kotlin 原生 Android，不新增依赖，不改包名和快递入口，不执行 GitHub 提交/推送/PR。先交 APK 给用户试用，用户确认后再处理公开仓库。

- `watermark-core/.../Models.kt`：默认位置改为右下；formattedFields 仅返回非空、已选中的原始内容，不拼字段标签。
- `app/.../ui/ContentPanel.kt`：六标签下方增加 48dp 高的原生位置选择按钮，单选左上/右上/左下/右下/底部居中，支持取消。按钮不增加整排选项，保持小屏紧凑。
- `app/.../ui/WatermarkActivity.kt`：预览更新时刷新位置按钮，拖动后显示“自由移动”；继续共用原图坐标的渲染器，不改导出管线。
- `app/.../data/LocalStore.kt`：配置 JSON 写入版本 2、兼容读取 1/2。只在读旧编辑器配置且 style 完全等于旧默认值时将左下映射为右下；保留旧模板、已拖动/改过样式的位置。新版主动选左下后不会再次被迁移。
- `app/build.gradle.kts`：versionName 1.3.0、versionCode 4，签名方式和权限不变。
- 新增 `PlainWatermarkTest`、`PositionAndPlainContentTest`；更新旧格式化字面预期及 ExportDialogFlowTest/UpgradeFixtureTest 的新行为断言。
- README、STATUS、TASKS、CHANGELOG 与使用说明同步；旧版说明保留在历史归档/1.2.0。

以上 app 源文件在 `app/src/main/java/cn/campuslife/assistant/`，核心源文件在 `watermark-core/src/main/kotlin/cn/campuslife/watermark/`。
