# 公共校园地点 · 1.5.1

## 统一内置数据

`CampusCatalog.kt`保存45项内置名称/别名，`assets/pingtan-coordinates.json`为用户最新schema2快照，含35坐标、2自定义名称、hiddenIds9。默认38项可见，35定位、3待核对。地图和搜索共用当前可见快照，不混入店铺。

学生宿舍显示“1号楼”等，教师完整名、实训X楼；旧简称/中文数字/全角可搜。实训1楼北/南门与校区北/南门ID分开。新自定义“实训2北门/实训2南门”保持用户名称和坐标，不借用校门位置。

最新文件已清掉实训2楼、心理健康教育示范基地的坐标，校区南门也无坐标；保留名称待核对，不补回旧点。校区北门已有记录，6号楼及快递驿站按新文件更新。手工/供应方位置不代表专业测绘或入口通行保证。

9项默认隐藏：校史馆、校友港湾、书语咖啡、师生服务大厅、小型消防站、安全体验馆、商贸实训超市、学生创业中心、员工宿舍。隐藏不删除名称或坐标，可恢复；不要求补全不用的地点。

## 调试包维护

1. “地点 → 新增自定义地点”：填公共名称/分类，保存后在高德长按真实入口并确认。不自动取手机位置；空名/重复别名/超长名称拒绝。
2. “管理自定义地点”：改名/分类保留坐标，调整位置取消保留旧点，删除须确认并同时移除其名称/坐标。最多200项。
3. “显示或隐藏地点”：勾选后保存，取消不变；校园搜索/标记/临时候选/原图锚点共用可见状态。
4. “退出核对模式”停止长按标点。“原图”入口仍可选楼回高德标注；42图面锚点只是选楼/高亮，不是GPS。新增/校门无锚点时明示。
5. 用户明确移除“从名单选择地点”“删除已标位置”“导出公共地点表”，不再提供这些菜单或长按隐藏入口。普通内置项仍可从原图重标；自定义删除没有取消。

维护草稿只在本机保存，不改照片/身份资料，不自动同步别人。正式release禁用维护入口及本机维护草稿，统一读取内置数据；当前交付为debug测试包。开发者更新公共asset后再打包分发，普通用户不用重复标点。当前没有导出/云端同步/文件导入界面。

## 存储与升级

schema2同时存`customPlaces`、`hiddenIds`、位置/来源/复核状态，底层编解码仍供存储/开发维护使用，不是对外文件导出功能。schema1只继承默认隐藏，不合并内置坐标；schema2保留自身显示设置。旧草稿是权威完整快照，已删除点不复活；不要清数据来恢复默认，否则会丢本机资料/草稿。

用户附件不覆盖。最新数据逐ID/经纬度/来源/自定义名称核对后内置；公共记录不要填写个人姓名/电话/寝室房间信息。不假定原图或供应方数据拥有公开再分发权。
